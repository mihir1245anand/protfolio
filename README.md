# Mihir Anand — Developer Portfolio

Personal developer portfolio website of **Mihir Anand** (2nd Year B.Tech CSE Student @ ABES Engineering College).

## 🚀 Live Features
- **Modern Dark Theme**: Custom emerald & cyan gradients, glowing ambient orbs, and subtle grid patterns.
- **Dynamic Typewriter**: Multi-role animated writing with real-time icon morphing and laser neon cursor.
- **Skills Showcase**: Categorized skill levels with smooth scroll-triggered progress bar animations.
- **Competitive Programming & Profiles**: CodeChef (1★ Rated), LinkedIn, LeetCode, and GitHub links.
- **Interactive Contact Form**: Client-side validation and simulated message dispatch with response feedback.
- **Fully Responsive**: Optimized for ultra-wide desktop, tablet, and mobile screens.

## 🛠️ Built With
- **HTML5** — Semantic Structure & SEO Meta Tags
- **CSS3** — Custom Properties, Glassmorphism, Keyframe Animations
- **JavaScript (ES6+)** — Interactive Behaviors & DOM Controls

## 🌐 Quick Start
Simply open `index.html` in any modern web browser or serve locally:
```bash
# Using Python
python -m http.server 5173

# Or using Node
npx serve .
```
